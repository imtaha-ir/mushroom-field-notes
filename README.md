# یادداشت‌های میدانی قارچ (Mushroom Field Notes)

یک PWA آفلاین برای ثبت اطلاعات نمونه‌های قارچ در سفرهای قارچ‌نگری، مطابق فرم کاغذی
«کارگروه تحقیق و توسعه گردشگری - موسسه گردشگران پایدار گیل».

## ویژگی‌ها
- کاملاً آفلاین: تمام داده‌ها (شامل عکس‌ها) در IndexedDB مرورگر ذخیره می‌شوند، بدون نیاز به سرور یا اینترنت پس از بار اول.
- قابل نصب روی موبایل به‌عنوان اپلیکیشن (PWA) با آیکون اختصاصی.
- صفحه‌ی اول: فهرست برنامه‌های قارچ‌نگری + دکمه‌ی شناور برای افزودن برنامه جدید.
- صفحه‌ی هر برنامه: فهرست نمونه‌های ثبت‌شده به همراه عکس بندانگشتی + دکمه‌ی «نمونه جدید».
- فرم کامل ثبت/ویرایش نمونه، بخش‌بندی‌شده مطابق فرم کاغذی اصلی (محل و محیط، کلاهک، زیر کلاهک، پایه، گوشت قارچ، شیره/بو/اسپورپرینت، عکس‌ها، یادداشت).
- گرفتن عکس مستقیم از دوربین یا انتخاب از گالری، با فشرده‌سازی خودکار قبل از ذخیره.
- رابط کاربری راست‌به‌چپ (RTL) و بهینه برای موبایل، با MUI.

## اجرای پروژه

نصب پیش‌نیازها (به اینترنت نیاز دارد؛ فقط بار اول):

```bash
npm install
```

اجرای حالت توسعه:

```bash
npm run dev
```

ساخت نسخه‌ی نهایی برای انتشار/نصب PWA:

```bash
npm run build
npm run preview   # برای تست خروجی build به‌صورت محلی
```

خروجی نهایی در پوشه‌ی `dist` قرار می‌گیرد. کافی است این پوشه را روی هر هاست استاتیک
(مثلاً GitHub Pages، Netlify، Vercel یا حتی یک سرور استاتیک ساده‌ی داخلی) قرار دهید؛
پس از اولین بازدید، برنامه به‌طور کامل آفلاین کار می‌کند و روی موبایل قابل «Add to Home Screen» است.

## نکات درباره‌ی داده‌ها
- همه‌چیز فقط در همان مرورگر/دستگاه ذخیره می‌شود (بدون همگام‌سازی ابری).
- پاک‌کردن Cache/Storage مرورگر باعث پاک‌شدن اطلاعات می‌شود؛ برای پشتیبان‌گیری در آینده
  می‌توان قابلیت Export/Import JSON اضافه کرد (در نسخه‌ی فعلی پیاده‌سازی نشده).

## پیش‌فرض‌هایی که در پیاده‌سازی فرم گرفته شده
با توجه به ریزبودن برخی گزینه‌های چاپ‌شده در فرم اسکن‌شده، این تفسیرها انجام شد:
- ردیف ۱۴ («عکس ثبت شد؟») به‌جای چک‌باکس ساده، به یک سامانه‌ی واقعیِ گرفتن/برچسب‌زدن عکس تبدیل شد
  (با برچسب‌های زیستگاه / بالای کلاهک / زیر کلاهک / برش عرضی / پایه / سایر) تا هم عکس واقعی ثبت شود
  و هم زاویه‌ی آن مشخص باشد.
- گزینه‌های «سایر» در هر بخش با یک فیلد توضیح متنی همراه شدند.
- «بو» به‌صورت گزینه‌های چندحالته (خنثی/تند/ملایم/نامطبوع/خوشبو/قابل تشخیص نیست) پیاده شد.
اگر عبارت‌بندی دقیق فرم اصلی شما با این‌ها فرق دارد، به‌راحتی می‌توان آن‌ها را در
`src/constants/formOptions.js` ویرایش کرد.
