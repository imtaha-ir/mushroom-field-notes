# Mushroom Field Notes

دفترچه‌ی میدانی دیجیتال برای ثبت، سازمان‌دهی و مرور مشاهدات قارچ در محل؛ سریع، خصوصی و قابل استفاده حتی بدون اتصال اینترنت.

## چرا Mushroom Field Notes؟

در طبیعت، ثبت مشاهده نباید به آنتن‌دهی یا فرم‌های پراکنده وابسته باشد. این محصول یک فضای ساده و متمرکز برای ساختن سفرهای میدانی، ثبت نمونه‌ها و نگه‌داشتن عکس‌ها و ویژگی‌های هر مشاهده فراهم می‌کند.

## امکانات اصلی

- ساخت و مدیریت چند سفر یا برنامه‌ی میدانی
- ثبت نمونه‌های متعدد در هر سفر با امکان ویرایش اطلاعات
- فرم ساختاریافته برای محیط، محل مشاهده، کلاهک، زیر کلاهک، پایه، گوشت، بو، شیره و اسپورپرینت
- ثبت یادداشت آزاد برای جزئیات تکمیلی
- افزودن عکس از دوربین یا گالری با برچسب‌گذاری زاویه‌ی عکس
- فشرده‌سازی خودکار تصاویر برای کاهش مصرف فضای دستگاه
- ذخیره‌سازی محلی و عملکرد آفلاین پس از اولین بارگذاری
- رابط راست‌به‌چپ و طراحی مناسب استفاده در موبایل
- نصب به‌عنوان اپلیکیشن روی دستگاه‌های سازگار با PWA

## شروع سریع برای کاربران

1. برنامه را در مرورگر باز کنید.
2. یک سفر میدانی بسازید.
3. برای هر مشاهده، نمونه‌ی جدیدی ثبت کنید.
4. عکس‌ها و ویژگی‌های قابل مشاهده را همان‌جا اضافه کنید.

برای بهترین تجربه، برنامه را پس از اولین بارگذاری به صفحه‌ی اصلی موبایل اضافه کنید.

## حریم خصوصی و نگه‌داری داده

اطلاعات و تصاویر در حافظه‌ی محلی همان مرورگر و دستگاه ذخیره می‌شوند و در نسخه‌ی فعلی به سرور یا حساب کاربری ارسال نمی‌شوند. بنابراین:

- پاک‌کردن داده‌های سایت یا حافظه‌ی مرورگر می‌تواند اطلاعات ثبت‌شده را حذف کند.
- اطلاعات بین دستگاه‌ها همگام نمی‌شود.
- پیش از تعویض دستگاه یا پاک‌سازی مرورگر، از داده‌های مهم خود نسخه‌ی پشتیبان تهیه کنید.

## اجرای نسخه‌ی توسعه

پیش‌نیاز: Node.js و npm

```bash
npm install
npm run dev
```

برای ساخت و بررسی نسخه‌ی قابل انتشار:

```bash
npm run build
npm run preview
```

خروجی تولیدشده در پوشه‌ی `dist` قرار می‌گیرد و می‌تواند روی هر سرویس میزبانی فایل‌های استاتیک منتشر شود.

## فناوری‌ها

- React 18
- Vite
- Material UI
- IndexedDB برای ذخیره‌سازی محلی
- Vite PWA برای قابلیت نصب و استفاده‌ی آفلاین

## وضعیت محصول

این نسخه برای ثبت آفلاین مشاهدات شخصی آماده است. همگام‌سازی ابری، حساب کاربری و خروجی‌گرفتن از داده‌ها در نسخه‌ی فعلی ارائه نشده‌اند.
